# Adobe CEP Plugin Dev: a Claude skill for building and fixing Adobe panels
This is a skill for Claude. Once installed, it helps with Adobe CEP panel work: scaffolding a new plugin, tracking down why a panel is blank or throws “EvalScript error”, fixing the bridge between the UI and ExtendScript, and packaging a signed .zxp. It also covers the CEP to UXP schedule, so you know which apps are safe to keep building on CEP today.

Install: download adobe-cep-plugin-dev.skill from the releases page and add it in Claude’s skill settings.
